## Функциональность
* **Генерация уравнений:** автоматическое создание систем булевых уравнений в КНФ или ДНФ с заданным числом переменных и уравнений
* **Решение уравнений:** поиск частных решений для каждого уравнения и системы в целом
* **Синтез тестов:** генерация тестовых наборов для проверки работоспособности логических схем
* **Визуальный интерфейс:** удобное управление через Windows Forms

## Стек технологий
* **Язык программирования:** C#
* **Среда разработки:** Visual Studio 2019
* **Платформа:** .NET

## Алгоритмы

### 1. Генератор уравнений

Функция: `generate(int k, int n)`

Принцип работы:  
Генератор создаёт случайные булевы уравнения в:  
- **КНФ** (конъюнктивная нормальная форма) — произведение сумм
- **ДНФ** (дизъюнктивная нормальная форма) — сумма произведений

Параметры генерации:  
- `k` — число внешних переменных
- `n` — максимальное число внутренних переменных в одном терме

Каждое уравнение содержит случайное количество термов (от 1 до n), каждый терм содержит случайный набор переменных с возможными отрицаниями.

### 2. Алгоритм решения уравнений

Основной алгоритм: `algoritm(string[,] Vectors, bool isKNF)`

Принцип работы:  
Алгоритм решает уравнение вида:  
- **КНФ = 1** — все дизъюнкции должны быть истинны
- **КНФ = 0** — хотя бы одна дизъюнкция должна быть ложна
- **ДНФ = 0** — все конъюнкции должны быть ложны
- **ДНФ = 1** — хотя бы одна конъюнкция должна быть истинна

Этапы работы:
1. **Преобразование уравнения** в массив векторов (маска наличия переменных и их значений)
2. **Поиск единичных векторов** (термов), содержащих только одну переменную
3. **Жадный алгоритм**: последовательный подбор значений переменных на основе частотности
4. **Проверка противоречий**: обнаружение ситуаций, когда уравнение не имеет решений

Специальные подалгоритмы:
- `sub_algoritm` — для уравнений вида КНФ=0 и ДНФ=1 (тривиальное решение)
- `greedy_algoritm` — жадный алгоритм выбора следующей переменной для подстановки
- `possible_to_replace` — проверка возможности замены значения переменной

### 3. Решение системы уравнений

Алгоритм: `system_solution(string[] answers)`

Принцип работы:  
1. Находит частные решения для каждого уравнения
2. Сравнивает их и ищет общие значения переменных
3. При возникновении конфликтов пытается изменить решение с помощью `possible_to_replace`
4. Возвращает совместное решение системы или сообщение об отсутствии решений

### 4. Синтез тестов

Алгоритм: `synthesis_of_tests(string[] answers)`

Принцип работы:  
1. Подставляет найденные значения переменных в исходные уравнения
2. Вычисляет значение каждого уравнения при подстановке
3. Формирует тестовый набор для проверки логической схемы
